# BH - BloodHound CE Quick Launcher
## BH Help Menu
```bash
BloodHound CE Manager

  bh up              Start all containers (detached)
  bh down            Stop all containers
  bh status          Show container status
  bh logs [service]  Tail logs (default: bloodhound)
  bh password        Show initial admin password from logs
  bh reset           Stop and wipe all data volumes
  bh url             Print the UI URL
```
